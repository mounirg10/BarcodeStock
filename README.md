# BarcodeStock — مخزون الباركود

تطبيق أندرويد (Kotlin + Jetpack Compose) لقراءة الباركود بالكاميرا وحفظ بيانات المنتج:
الاسم، السعر، الكمية، تاريخ الدخول، تاريخ نهاية الصلاحية.

## الميزات الجديدة

- 🔔 **إشعار تلقائي قبل يومين**: فحص يومي عبر WorkManager الساعة 9 صباحًا يرسل تنبيهًا لكل منتج تنتهي صلاحيته خلال يومين أو أقل (يعمل حتى لو كان التطبيق مغلقًا وبدون إنترنت).
- 📗 **نسخة احتياطية Excel**: زر في شريط العنوان ينشئ ملف `.xlsx` حقيقي بكل المنتجات ثم يفتح قائمة المشاركة/الحفظ (Drive، واتساب، الإيميل، الملفات). دون أي مكتبة خارجية.

## طريقة 1: إنتاج APK عبر GitHub (بدون تثبيت أي برنامج)

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع محتوى هذا المجلد كاملاً (بما فيه مجلد `.github`).
3. افتح تبويب **Actions** ← سيعمل مسار البناء تلقائيًا (أو اضغط Run workflow).
4. بعد 3-6 دقائق حمّل ملف **BarcodeStock-debug-apk** من قسم Artifacts.
5. انقل الـ APK إلى الهاتف وثبّته (فعّل "تثبيت من مصادر غير معروفة").

## طريقة 2: عبر Android Studio

1. `File → Open` ثم اختر مجلد المشروع وانتظر Gradle Sync.
2. `Build → Build Bundle(s)/APK(s) → Build APK(s)`.
3. ستجد الملف في `app/build/outputs/apk/debug/app-debug.apk`.
